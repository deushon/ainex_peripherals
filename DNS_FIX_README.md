# Исправление проблемы с DNS настройками

## Проблема
DNS настройки постоянно сбрасываются после перезагрузки, что мешает подключению к Git и другим интернет-сервисам.

## Решение
Установлены следующие механизмы для автоматического восстановления DNS:

### 1. Статическая конфигурация DNS
Файл `/etc/resolv.conf` настроен с использованием надежных DNS серверов:
- Google DNS: 8.8.8.8, 8.8.4.4
- Cloudflare DNS: 1.1.1.1, 1.0.0.1 (резервные)

### 2. Скрипт автоматического восстановления
Скрипт `/home/ubuntu/ros_ws/src/ainex_peripherals/scripts/fix_dns.sh`:
- Проверяет наличие DNS серверов в `/etc/resolv.conf`
- Автоматически восстанавливает их при необходимости

### 3. Автозагрузка при старте системы
Скрипт настроен на запуск при загрузке через:
- **rc.local** (`/etc/rc.local`) - основной метод для систем без systemd
- **systemd service** (`/etc/systemd/system/fix_dns.service`) - для систем с systemd

### 4. Дополнительный мониторинг (опционально)
Скрипт `/home/ubuntu/ros_ws/src/ainex_peripherals/scripts/fix_dns_monitor.sh` можно использовать для периодической проверки DNS (например, через cron).

## Использование

### Ручное восстановление DNS
Если DNS снова слетел, просто запустите:
```bash
sudo /home/ubuntu/ros_ws/src/ainex_peripherals/scripts/fix_dns.sh
```

### Проверка DNS
```bash
host google.com
# или
ping -c 1 google.com
```

### Проверка текущих DNS серверов
```bash
cat /etc/resolv.conf
```

- После перезагрузки скрипт автоматически восстановит DNS настройки через `rc.local`
- Если проблема сохраняется, можно запустить скрипт вручную
- Все изменения требуют прав root (используйте `sudo`)
