# Диагностика проблемы с камерой

## Текущая ситуация

**Проблема:** Нода `/camera` запущена, но не публикует данные в топик `/camera/image_raw`

## Найденные проблемы

### 1. USB камера не обнаружена системой
- **Ожидаемые USB ID камер** (из `99-usb-cam.rules`):
  - `090c:b371`
  - `32e6:9005`
  - `32e6:9251`
  - `32e6:9221`

- **Фактически подключенные USB устройства:**
  - `1a86:7523` - USB Serial (CH341)
  - `1b3f:2008` - USB Audio Device
  - `05e3:0610` - USB2.1 Hub

**Вывод:** USB камера с ожидаемыми ID не подключена или не распознается.

### 2. Устройство `/dev/usb_cam` не существует
- Launch файл указывает на `/dev/usb_cam`
- Симлинк не создан, т.к. камера не обнаружена
- udev правила не сработали (камера не найдена)

### 3. Драйвер uvcvideo отсутствует
- Модуль `uvcvideo` не найден в ядре `6.6.31+rpt-rpi-2712`
- Это может быть проблема с ядром Raspberry Pi или отсутствием драйвера

## Рекомендации по решению

### Шаг 1: Проверка физического подключения
1. Убедитесь, что USB камера физически подключена
2. Попробуйте переподключить камеру в другой USB порт
3. Проверьте, работает ли камера на другом компьютере

### Шаг 2: Проверка после подключения камеры
После подключения камеры выполните:
```bash
# Проверка подключения
sudo dmesg | tail -20

# Проверка USB устройств
for dir in /sys/bus/usb/devices/5-1*/; do 
  if [ -f "$dir/idVendor" ]; then 
    vendor=$(cat $dir/idVendor 2>/dev/null); 
    product=$(cat $dir/idProduct 2>/dev/null); 
    name=$(cat $dir/product 2>/dev/null || echo "Unknown"); 
    echo "$(basename $dir): Vendor=$vendor Product=$product Name=$name"; 
  fi; 
done

# Проверка video устройств
ls -la /dev/video*
v4l2-ctl --list-devices
```

### Шаг 3: Установка udev правил
Если камера подключена, но симлинк не создан:
```bash
sudo cp /home/ubuntu/ros_ws/src/ainex_peripherals/scripts/99-usb-cam.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger --subsystem-match=video4linux
```

### Шаг 4: Проверка драйвера uvcvideo
Если камера подключена, но не видна:
```bash
# Проверка наличия драйвера
find /lib/modules/$(uname -r) -name "*uvc*"

# Попытка загрузки драйвера
sudo modprobe uvcvideo

# Проверка загруженных модулей
lsmod | grep uvc
```

### Шаг 5: Альтернативное решение
Если камера имеет другой USB ID или использует другое устройство:
1. Определите правильное устройство: `v4l2-ctl --list-devices`
2. Измените launch файл или создайте симлинк:
   ```bash
   sudo ln -s /dev/videoXX /dev/usb_cam
   ```

## Текущий статус ноды

- Нода `/camera` запущена (PID виден в `rosnode info`)
- Топик `/camera/image_raw` существует
- Нода не может получить доступ к `/dev/usb_cam` (устройство не существует)
- Данные не публикуются из-за отсутствия доступа к камере

## Следующие шаги

1. **Проверьте физическое подключение камеры**
2. **После подключения проверьте USB ID камеры**
3. **Если USB ID отличается от ожидаемых, обновите udev правила или launch файл**
4. **Перезапустите ноду камеры после исправления**
