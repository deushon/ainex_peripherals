# Настройка и калибровка PID стабилизации

## Установка

Установите библиотеку `simple-pid`:

```bash
pip install simple-pid
```

Или для Python 3:

```bash
pip3 install simple-pid
```

## Конфигурация

Параметры PID настраиваются в файле `config/walking.yaml`:

```yaml
walking:
  stabilization_pid:
    enabled: true
    setpoint: 90.0      # Целевое значение pitch (градусы)
    kp: 0.001           # Пропорциональный коэффициент
    ki: 0.0             # Интегральный коэффициент
    kd: 0.0             # Дифференциальный коэффициент
    upper_limit: 0.05   # Максимальное init_x_offset
    lower_limit: -0.05  # Минимальное init_x_offset
```

## Начальная настройка PID

### Шаг 1: Начните с P-регулятора (только пропорциональная составляющая)

Установите в `config/walking.yaml`:
```yaml
stabilization_pid:
  enabled: true
  setpoint: 90.0
  kp: 0.001
  ki: 0.0
  kd: 0.0
```

**Что делать:**
1. Запустите систему и наблюдайте за поведением робота
2. Если реакция слишком слабая - увеличьте `kp` (например, 0.002, 0.005)
3. Если появляются колебания - уменьшите `kp`
4. Найдите значение `kp`, при котором робот реагирует, но еще нет сильных колебаний

### Шаг 2: Добавьте интегральную составляющую (устранение статической ошибки)

Если робот не достигает целевого значения pitch (остается ошибка):
```yaml
stabilization_pid:
  kp: 0.001  # Значение из шага 1
  ki: 0.0001  # Начните с очень малого значения
  kd: 0.0
```

**Что делать:**
1. Начните с `ki = kp / 100` (очень маленькое значение)
2. Постепенно увеличивайте `ki`, если ошибка не устраняется
3. **Внимание:** Слишком большое `ki` может вызвать перерегулирование и колебания
4. Если появляются колебания - уменьшите `ki`

### Шаг 3: Добавьте дифференциальную составляющую (уменьшение колебаний)

Если есть колебания или перерегулирование:
```yaml
stabilization_pid:
  kp: 0.001
  ki: 0.0001
  kd: 0.0001  # Начните с малого значения
```

**Что делать:**
1. Начните с `kd = kp / 10` (малое значение)
2. Увеличивайте `kd` для уменьшения колебаний
3. **Внимание:** Слишком большое `kd` может вызвать резкие движения при шуме в данных IMU
4. Если движения становятся резкими - уменьшите `kd`

## Метод Ziegler-Nichols (для продвинутых)

Этот метод помогает найти оптимальные параметры:

### 1. Настройка P-регулятора до появления устойчивых колебаний

1. Установите `ki = 0.0`, `kd = 0.0`
2. Увеличивайте `kp` до появления устойчивых колебаний
3. Запишите значение `kp` как `Ku` (критический коэффициент)
4. Измерьте период колебаний `Tu` (в секундах)

### 2. Вычисление параметров PID

Используйте формулы Ziegler-Nichols:

**Для PID контроллера:**
- `kp = 0.6 * Ku`
- `ki = 1.2 * Ku / Tu`
- `kd = 3 * Ku * Tu / 40`

### 3. Тонкая настройка

После получения начальных значений, настройте параметры вручную для лучшего результата.

## Типичные значения для стабилизации робота

### Консервативные (медленная, но стабильная реакция):
```yaml
kp: 0.0005
ki: 0.0
kd: 0.0
```

### Умеренные (баланс скорости и стабильности):
```yaml
kp: 0.001
ki: 0.0001
kd: 0.0001
```

### Агрессивные (быстрая реакция, но возможны колебания):
```yaml
kp: 0.005
ki: 0.0005
kd: 0.0005
```

## Настройка setpoint

`setpoint` - это целевое значение pitch, к которому стремится контроллер.

- **90°** - вертикальное положение (по умолчанию)
- **Другие значения** - если нужно стабилизировать под углом

## Настройка limits (пределов выходного сигнала)

`upper_limit` и `lower_limit` ограничивают значение `init_x_offset`:

- **Слишком большие значения** (например, ±0.1) - сильные корректировки, возможны резкие движения
- **Слишком маленькие значения** (например, ±0.01) - слабые корректировки, может не хватать для стабилизации
- **Рекомендуемые**: ±0.05 (по умолчанию)

## Визуализация и отладка

### Включение логирования

Раскомментируйте в `walking/stabilization.py`:
```python
rospy.logdebug(f"[PID STABILIZATION] pitch={pitch_deg:.2f}°, setpoint={self.pid_setpoint}°, "
              f"control_effort={init_x_offset:.4f}")
```

Затем установите уровень логирования:
```bash
rosparam set /rosout/level DEBUG
```

### Мониторинг через ROS topics

Можно добавить публикацию данных PID для визуализации (опционально, в `stabilization.py`):
```python
# В process() после вычисления init_x_offset:
self.pid_state_pub.publish(Float64(pitch_deg))
self.pid_setpoint_pub.publish(Float64(self.pid_setpoint))
self.pid_control_effort_pub.publish(Float64(init_x_offset))
```

Затем визуализируйте через `rqt_plot`:
```bash
rosrun rqt_plot rqt_plot
# Добавьте topics: /stabilization_pid/state, /stabilization_pid/setpoint, /stabilization_pid/control_effort
```

## Устранение проблем

### Проблема: Робот не реагирует на изменения pitch

**Решение:**
- Увеличьте `kp` (например, с 0.001 до 0.005)
- Проверьте, что `enabled: true` в конфиге
- Проверьте, что данные IMU поступают

### Проблема: Сильные колебания

**Решение:**
- Уменьшите `kp`
- Увеличьте `kd` (дифференциальная составляющая уменьшает колебания)
- Уменьшите `ki` (интегральная составляющая может вызывать перерегулирование)

### Проблема: Медленная реакция

**Решение:**
- Увеличьте `kp`
- Проверьте, что частота обновления IMU достаточна (обычно 50 Hz)

### Проблема: Статическая ошибка (не достигает setpoint)

**Решение:**
- Увеличьте `ki` (но осторожно, может вызвать колебания)
- Начните с очень малого значения (например, `ki = kp / 100`)

### Проблема: Резкие движения

**Решение:**
- Уменьшите `kd` (дифференциальная составляющая чувствительна к шуму)
- Уменьшите `upper_limit` и `lower_limit`
- Проверьте качество данных IMU (возможен шум)

## Рекомендации по калибровке

1. **Начните с малых значений** - лучше медленная, но стабильная работа
2. **Настраивайте по одному параметру** - сначала `kp`, затем `ki`, затем `kd`
3. **Тестируйте в безопасных условиях** - убедитесь, что робот не упадет
4. **Записывайте значения** - ведите журнал настроек для разных режимов работы
5. **Учитывайте режим ходьбы** - возможно, нужны разные параметры для разных скоростей

## Примеры конфигураций

### Для медленной ходьбы (режим 1-2):
```yaml
stabilization_pid:
  kp: 0.0008
  ki: 0.00005
  kd: 0.0001
```

### Для быстрой ходьбы (режим 3-4):
```yaml
stabilization_pid:

  ki: 0.0002
  kd: 0.0003
```
