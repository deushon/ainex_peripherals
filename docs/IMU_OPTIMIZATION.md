# Оптимизация задержки обработки IMU

## Фильтры IMU

Фильтры настраиваются в `launch/imu.launch`:

### Complementary Filter (строки 31-41)

```xml
<node name="imu_filter" pkg="imu_complementary_filter" type="complementary_filter_node" >
    <param name="gain_acc"            value="0.2"/>      <!-- Коэффициент фильтрации акселерометра -->
    <param name="bias_alpha"          value="0.2"/>      <!-- Коэффициент оценки смещения -->
    <param name="do_bias_estimation"  value="true"/>    <!-- Оценка смещения -->
    <param name="do_adaptive_gain"    value="true"/>     <!-- Адаптивный коэффициент -->
</node>
```

### Параметры для максимальной скорости реакции:

**Текущие значения (более стабильные, но медленнее):**
- `gain_acc = 0.2` - больше фильтрации, меньше шум, но медленнее реакция
- `bias_alpha = 0.2` - медленнее адаптация к смещению

**Рекомендуемые для быстрой реакции:**
- `gain_acc = 0.1-0.15` - меньше фильтрации, быстрее реакция, но больше шум
- `bias_alpha = 0.1-0.15` - быстрее адаптация

**Экстремальные (максимальная скорость, но больше шум):**
- `gain_acc = 0.05-0.1` - минимальная фильтрация
- `bias_alpha = 0.05-0.1` - быстрая адаптация

⚠️ **Внимание:** Меньшие значения = быстрее реакция, но больше шум и возможные колебания.

## Оптимизации в коде

### 1. Кэширование параметров
- `gait_param` кэшируется и обновляется только при изменении `speed_mode`
- Уменьшает количество вызовов `get_gait_param()` (дорогая операция)

### 2. Прямой доступ к данным
- Заменены `.get()` вызовы на прямое обращение к словарям
- Уменьшает overhead на проверки наличия ключей

### 3. Отключено логирование в стабилизации
- `rospy.loginfo` в `stabilization.py` отключен (можно включить через `logdebug`)
- Логирование - одна из самых медленных операций

### 4. Минимизировано создание объектов
- Оптимизировано создание словарей и объектов данных

## Дополнительные рекомендации

1. **Уменьшить частоту публикации IMU** (если возможно):
   - Текущая частота обычно 50-100 Hz
   - Для стабилизации достаточно 30-50 Hz

2. **Использовать более быстрый процессор** для ROS узлов

3. **Уменьшить размер очереди ROS**:
   ```python
   self.imu_sub = rospy.Subscriber('/imu', Imu, self.imu_callback, queue_size=1)
   ```

4. **Отключить ненужные узлы** в `imu.launch`:
   - `tf_broadcaster_imu` (если не нужен)
   - `rviz` (только для отладки)

## Измерение задержки

Для измерения задержки можно добавить временные метки:

```python
def imu_callback(self, msg: Imu):
    msg_time = msg.header.stamp.to_sec()
    current_time = rospy.get_time()
    latency = current_time - msg_time
    rospy.logdebug(f"IMU latency: {latency*1000:.2f} ms")
```

Целевая задержка: < 20-30 мс от получения IMU до применения стабилизации.
