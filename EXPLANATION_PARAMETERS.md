# Объяснение параметров GaitManager

## Разница между `init_pitch_offset` и `hip_pitch_offset`

### `init_pitch_offset` (начальный тангаж корпуса)

**Что это:**
- Угол наклона **всего корпуса** робота вперед/назад относительно горизонтали
- Измеряется в градусах
- Применяется к **всему телу** как единому целому
- Влияет на **центр масс** всего робота

**Как работает:**
- Положительное значение = наклон вперед (нос вниз)
- Отрицательное значение = наклон назад (нос вверх)
- Вращение происходит вокруг **поперечной оси** (ось Y) в точке опоры

**Когда использовать:**
- Для компенсации наклона всего корпуса вперед/назад
- При стабилизации на наклонной поверхности
- Для изменения центра масс при движении
- Для компенсации постоянного наклона (например, при подъеме в гору)

**Пример:**
```python
# Робот наклоняется вперед на 5 градусов
gait_param['init_pitch_offset'] = 5.0  # Наклон вперед
# Это наклонит весь корпус, включая голову, туловище, таз
```

### `hip_pitch_offset` (наклон тазобедренного сустава)

**Что это:**
- Угол наклона **тазобедренного сустава** (бедра) относительно корпуса
- Измеряется в градусах
- Применяется только к **тазобедренным суставам** (бедрам)
- Влияет на **положение ног** относительно корпуса

**Как работает:**
- Положительное значение = бедра наклонены вперед (ноги выдвинуты вперед)
- Отрицательное значение = бедра наклонены назад (ноги отведены назад)
- Вращение происходит в **тазобедренных суставах**, а не во всем корпусе

**Когда использовать:**
- Для изменения походки (более агрессивная/осторожная)
- Для компенсации наклона при движении по наклонной поверхности
- Для улучшения баланса при быстром движении
- Для адаптации к разным типам поверхности

**Пример:**
```python
# Тазобедренные суставы наклонены на 20 градусов вперед
gait_param['hip_pitch_offset'] = 20.0  # Ноги выдвинуты вперед
# Корпус остается прямым, но ноги принимают другое положение
```

### Визуальное сравнение

```
init_pitch_offset = 5°:          hip_pitch_offset = 20°:

    [Голова]                          [Голова]
       |                                 |
    [Туловище] ← наклонено вперед      [Туловище] ← прямо
       |                                 |
    [Таз]                              [Таз]
       |                                 |
    [Ноги]                              [Ноги] ← выдвинуты вперед
```

### Когда использовать каждый параметр

**Используйте `init_pitch_offset` когда:**
- Нужно наклонить **весь корпус** (например, для компенсации наклона поверхности)
- Изменяется **центр масс** всего робота
- Робот движется по **наклонной поверхности** и нужно компенсировать наклон
- Нужна **быстрая коррекция** позы всего тела

**Используйте `hip_pitch_offset` когда:**
- Нужно изменить **положение ног** относительно корпуса
- Изменяется **стиль походки** (более агрессивный/осторожный)
- Нужно улучшить **баланс** при движении
- Корпус должен оставаться **прямым**, но ноги в другом положении

### Комбинированное использование

Можно использовать оба параметра одновременно:

```python
# Наклон корпуса вперед + выдвинутые ноги = агрессивная поза
gait_param['init_pitch_offset'] = 5.0   # Весь корпус наклонен вперед
gait_param['hip_pitch_offset'] = 20.0   # Ноги выдвинуты вперед
```

## Как используется `update_pose()`

### Назначение метода

`update_pose()` - это метод для **обновления позы робота без движения**. В отличие от `set_step()` или `update_param()`, он:
- **НЕ запускает движение**
- **НЕ выполняет шаги**
- Только **обновляет параметры позы** и публикует их

### Сигнатура метода

```python
def update_pose(self, walking_param):
    """
    Обновляет позу робота без движения.
    
    Args:
        walking_param: Словарь с параметрами позы
    """
```

### Что делает метод

1. **Проверяет состояние** - если модуль отключен, включает его
2. **Валидирует параметры** - проверяет диапазоны `body_height` и `step_height`
3. **Обновляет внутренние параметры** - копирует все значения из `walking_param`
4. **Обнуляет движение** - устанавливает `x_move_amplitude`, `y_move_amplitude`, `angle_move_amplitude` в 0
5. **Публикует параметры** - отправляет обновленные параметры через ROS топик

### Отличие от других методов

| Метод | Движение | Шаги | Использование |
|-------|----------|------|---------------|
| `set_step()` | ✅ Да | ✅ Да | Для движения с шагами |
| `update_param()` | ✅ Да | ✅ Да | Для обновления параметров и движения |
| `update_pose()` | ❌ Нет | ❌ Нет | Только для изменения позы |

### Когда использовать `update_pose()`

**Идеальные случаи:**

1. **Плавная коррекция позы без шагов**
   ```python
   # Робот стоит, нужно немного скорректировать наклон
   gait_param = gait_manager.get_gait_param()
   gait_param['init_pitch_offset'] = 2.0  # Небольшой наклон вперед
   gait_manager.update_pose(gait_param)  # Плавная коррекция без шагов
   ```

2. **Компенсация наклона в покое**
   ```python
   # Робот стоит на наклонной поверхности
   # Нужно компенсировать наклон без движения
   gait_param = gait_manager.get_gait_param()
   gait_param['init_roll_offset'] = -3.0  # Компенсация крена
   gait_param['init_pitch_offset'] = 5.0   # Компенсация тангажа
   gait_manager.update_pose(gait_param)
   ```

3. **Предварительная настройка перед движением**
   ```python
   # Настраиваем позу перед началом движения
   gait_param = gait_manager.get_gait_param()
   gait_param['hip_pitch_offset'] = 20.0  # Агрессивная поза
   gait_manager.update_pose(gait_param)  # Устанавливаем позу
   # Потом начинаем движение через set_step()
   ```

4. **Коррекция позы во время автостабилизации**
   ```python
   # Небольшое отклонение - корректируем позу без шага
   if abs(deviation) < SMALL_THRESHOLD:
       gait_param = gait_manager.get_gait_param()
       gait_param['init_roll_offset'] = -deviation * 5.0
       gait_manager.update_pose(gait_param)  # Плавная коррекция
   ```

### Пример использования в автостабилизации

```python
def _correct_pose_smoothly(self, ax, ay):
    """
    Плавно корректирует позу без шагов для небольших отклонений.
    """
    # Небольшие отклонения - используем update_pose
    if abs(ax) < 0.1 and abs(ay) < 0.1:
        gait_param = self.gait_manager.get_gait_param()
        
        # Коррекция крена (roll)
        if abs(ax) > 0.01:
            roll_compensation = -ax * 5.0
            roll_compensation = max(-10, min(10, roll_compensation))
            gait_param['init_roll_offset'] = roll_compensation
        
        # Коррекция тангажа (pitch)
        if abs(ay) > 0.01:
            pitch_compensation = -ay * 5.0
            pitch_compensation = max(-10, min(10, pitch_compensation))
            gait_param['init_pitch_offset'] = pitch_compensation
        
        # Плавная коррекция без шагов
        self.gait_manager.update_pose(gait_param)
        return True
    
    return False
```

### Преимущества `update_pose()`

1. **Плавность** - изменения применяются без резких движений
2. **Энергоэффективность** - нет лишних шагов
3. **Точность** - можно делать мелкие корректировки
4. **Безопасность** - не запускает движение, только меняет позу

### Ограничения

- **Не запускает движение** - если нужно движение, используйте `set_step()`
- **Только поза** - не влияет на параметры движения (period_time, dsp_ratio и т.д.)
- **Требует валидации** - параметры должны быть в допустимых диапазонах

## Рекомендации по использованию

### Для автостабилизации

1. **Малые отклонения** (< 0.1 м/с²) → используйте `update_pose()` для плавной коррекции
2. **Средние отклонения** (0.1-0.3 м/с²) → используйте `set_step()` с одним шагом
3. **Большие отклонения** (> 0.3 м/с²) → используйте `set_step()` с несколькими шагами

### Для компенсации наклона

1. **Наклон поверхности** → используйте `init_pitch_offset` для наклона всего корпуса
2. **Изменение походки** → используйте `hip_pitch_offset` для изменения положения ног
3. **Комбинированная компенсация** → используйте оба параметра вместе

### Для улучшения баланса

1. **Коррекция крена** → `init_roll_offset`
2. **Коррекция тангажа** → `init_pitch_offset`
3. **Изменение походки** → `hip_pitch_offset`
